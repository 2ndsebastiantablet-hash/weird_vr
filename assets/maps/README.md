# Legacy map assets

These uploaded GLB environment files are retained only as archived source assets:

- `street_city_buildings_8.glb`
- `mansion_furnished_quest.glb`
- `pine_forest.glb`

The live game no longer references or loads them. All three match environments are now generated from optimized A-Frame shapes, animated lights, emissive materials, and matching locomotion colliders by `map-loader.js`.
